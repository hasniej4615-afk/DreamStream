## 🎯 Quick Start Guides

### For TV Users
1. Use **DPAD Center** to play/pause.
2. Press **DPAD Down** during playback to browse all episodes.
3. Observe **Next Episode** starts automatically after the current one ends.

### For Mobile Users
1. Browsing is locked to **Portrait** for focus.
2. Video automatically rotates to **Landscape**.
3. **Pull to Refresh** to automatically discover the newest site domain.

### For Developers (DEBUG Mode)
1. Type `debug1` in the Search bar to unlock DEBUG settings.
2. Go to **Settings -> DEBUG** to manually update domains or enable mobile rotation.
